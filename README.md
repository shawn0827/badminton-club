# 羽球團工具 iPhone 整合版

同一個 App 內有兩個功能：

## 1. 收費計算

預設規則：
- 基準費用：2700
- 臨打 0 人：臨打場成本 1000
- 臨打 1 人以上：臨打場成本 1700
- 臨打：250 / 人
- 親友未滿 4 小時：250 / 人，不加入均分
- 外部歡樂場：350 / 人
- 打滿 4 小時親友才加入均分

公式：

[2700 - (臨打收入 - 臨打場成本)
      - (未滿4小時親友人數 × 250)
      - (外部歡樂場人數 × 350)]
÷ 打滿4小時親友人數

「臨打人數」預設直接使用上場輪轉名單人數，也可以取消勾選後手動輸入。

## 2. 上場輪轉

規則：
- 6 人以下：目標上 4 下 2
- 7–8 人：上 4 下 3
- 9 人以上：上 4 下 4

如果候補不足，會自動降低下場人數，以維持場上 4 人。例如：
- 4 人：沒有候補，所以 4 人續打
- 5 人：只有 1 位候補，所以實際下 1 人
- 6 人：下 2 人
- 7–8 人：下 3 人
- 9 人以上：下 4 人

程式會（隨機模式）：
- 顯示目前場上 4 人
- 顯示下一場 4 人
- 標示誰留場、誰準備上場
- 顯示候補順序
- 自動統計每人上場局數
- 第一場隨機抽 4 人；之後每局都重新隨機決定下場者與候補上場者
- 可直接修改姓名
- 排場前可新增、刪除、調整名單順序
- 排場中可修改打錯的姓名

## iPhone 使用

1. 把整個資料夾內容上傳到 GitHub repository 根目錄。
2. GitHub → Settings → Pages。
3. Deploy from a branch → main → /(root)。
4. Safari 開啟 GitHub Pages 網址。
5. Safari 分享 → 加入主畫面。

加入主畫面後可像 App 一樣使用，並支援離線快取。


## v3 使用體驗調整

- 臨打人數預設改為手動輸入。
- 需要輪轉名單人數時，按「使用輪轉名單人數」才會帶入。
- 人數欄位預設留白，不再顯示 0。
- 加入「常用球友」記憶：
  - 記住目前名單
  - 點常用球友即可加入本場
  - 全部加入本場
  - 清空本場名單不會刪除常用球友
- 名單仍保存在 iPhone 瀏覽器 localStorage。


## v4 人數輸入體驗

- 人數欄位實際預設為空白。
- 空白時畫面顯示淡灰色 `0` 當提示。
- 點擊欄位時不用先刪除 `0`。
- 輸入真正數字後，數字會自動顯示為深色。
